# Smart Checkout Fields Manager - Languages

This folder contains translation files for the plugin.

## Creating Translations

1. Use Loco Translate plugin or POEdit to create translations from the POT file
2. Create PO files for your language
3. Compile to MO files

## Text Domain

`smart-checkout-fields-manager`

## Example

- `smart-checkout-fields-manager-el_GR.po` - Greek translation
- `smart-checkout-fields-manager-el_GR.mo` - Greek compiled translation

## For WordPress.org

When hosted on WordPress.org, translations are handled automatically through translate.wordpress.org. The POT file is provided for local development and Loco Translate compatibility.
