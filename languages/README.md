# Smart Checkout Fields Manager - Languages

This folder contains translation files for the plugin.

## Creating Translations

1. Generate POT file using WordPress i18n tools
2. Create PO files for your language
3. Compile to MO files

## Text Domain

`smart-checkout-fields`

## Example

- `smart-checkout-fields-el_GR.po` - Greek translation
- `smart-checkout-fields-el_GR.mo` - Greek compiled translation
